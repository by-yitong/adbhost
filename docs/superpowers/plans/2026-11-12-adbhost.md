# AdbHost 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development(主 agent 派卡,子 agent 执行)。
> 步骤用 `- [ ]` 追踪。**必读:** `docs/PROTOCOL.md`(协议实证契约,冲突时以它为准)+ `docs/superpowers/specs/2026-11-12-adbhost-design.md`。

**Goal:** 原生 Android App 实现 ADB 设备端协议(TLS1.3 主路径 + 经典 RSA 兼容路径),电脑 adb 直连可用 shell/文件传输。

**Architecture:** 单 module 四层:core(纯 Kotlin 协议,JVM 可测)→ engine(ServerSocket+服务分发)→ platform(前台服务)→ ui(Compose)。主 agent 派卡,子 agent 按 package 边界执行。

**Tech Stack:** Kotlin 2.x、Jetpack Compose(M3)、kotlinx-coroutines、BouncyCastle bcpkix(证书)、JDK 工具链 17(Gradle 运行)、minSdk 28 / targetSdk 35 / arm64-v8a。

## Global Constraints

- 禁止修改接口契约与目录结构;新增依赖仅限 bcpkix(主 agent 已批)
- 协议常量/流程以 docs/PROTOCOL.md 为唯一权威;禁止注释;命名自解释
- 打包 abiFilters 仅 arm64-v8a;编码遵守工程规范(卡片内禁止再派生 agent)
- 每张卡交付必报:改动文件、验证方式与结果、遗留疑问

### Task 1(卡片A,general-purpose):core 协议内核 + JVM 单测

**Files:** `adbhost/src/main/java/com/adbhost/app/core/*.kt`、`adbhost/src/test/java/com/adbhost/app/core/*Test.kt`

**Interfaces(冻结,后续卡依赖):**
```kotlin
object AdbCommand { const val CNXN=0x4E584E43L; AUTH=0x48555441L; STLS=0x534C5453L; OPEN=0x4E45504FL; OKAY=0x59414B4FL; CLSE=0x45534C43L; WRTE=0x45545257L }
object AdbAuth { const val TOKEN=1L; SIGNATURE=2L; RSAPUBLICKEY=3L }
object ShellProtocol { const val STDIN=1; STDOUT=2; STDERR=3; EXIT=4; CLOSE=5 }
data class AdbMessage(val command:Long,val arg0:Long,val arg1:Long,val payload:ByteArray) {
  fun checksum(): Long; fun magic(): Long
  fun encode(out: OutputStream)   // 校验 payload<=maxPayload
  companion object { fun read(input: InputStream, maxPayload: Int): AdbMessage?; fun headerSize=24 }
}
class AdbPublicKeyCodec {
  fun encodeToAdbFormat(publicKey: RSAPublicKey, name: String): ByteArray  // len|n0inv|n[64]|rr[64]|exp + ' ' + name + '\0',再 base64 由调用方处理——本函数返回 base64 前的原始字节,含名字与 NUL
  fun decodeFromAdbFormat(b64Payload: ByteArray): RSAPublicKey            // 去掉 trailing '\0'+名字,解析结构
  fun fingerprintSha1(publicKey: RSAPublicKey): String                     // "AA:BB:.."
  fun fingerprintOfAdbPayload(b64Payload: ByteArray): String
}
class TrustStore(dir: File) {   // core 内纯文件实现
  fun trustedAdbPublicKeys(): List<RSAPublicKey>       // 经典模式,adb_keys 行格式
  fun trustedCertFingerprints(): Set<String>           // TLS 模式,SHA-1 指纹集
  fun addAdbPublicKey(line: String); fun addCertFingerprint(fp: String)
  fun removeAdbPublicKey(fp: String): Boolean; fun removeCertFingerprint(fp: String): Boolean
  fun listEntries(): List<TrustEntry>                  // data class TrustEntry(kind, fingerprint, name, addedAt)
}
class RsaIdentity(keyFile: File) {  // RSA-2048 生成/PKCS8 加载;cert 生成走 platform 注入的 CertificateFactory 接口
  val keyPair: KeyPair
  fun adbPublicKeyLine(name: String): String   // base64(encodeToAdbFormat)+" "+name(不含 NUL)
}
class AuthEngine(identity: RsaIdentity, trust: TrustStore) {
  fun verifySignature(token: ByteArray, signature: ByteArray): Boolean
  fun verifyHostCert(cert: Certificate): CertDecision   // enum CertDecision { TRUSTED, NEW, REJECTED }
}
class AdbConnection(
  input: InputStream, output: OutputStream,      // TLS 模式下为 TLS 流;由 engine 装配
  auth: AuthEngine, identity: RsaIdentity,
  tlsMode: Boolean, maxPayload: Int = 256*1024,
  localBanner: String,                            // device::ro.product...;features=...
  services: (service: String, localId: Long, remoteId: Long, conn: AdbConnection) -> ServiceHandler,
  onAuthorizationRequest: (fingerprint: String, name: String, respond: (Boolean)->Unit) -> Unit,
  log: (String)->Unit,
) : Closeable {
  fun startHandshakeAndLoop()   // 阻塞式;CNXN 交换→STLS/TOKEN 分支→在线循环;断开返回
  fun sendMessage(msg: AdbMessage); fun closeService(remoteId: Long)
  val authorized: Boolean
}
interface ServiceHandler : Closeable { fun onPayload(data: ByteArray); fun onClosed() }
```

**关键实现要点(必按):**
1. 帧读写:`read` 先读 24B,校验 magic==command^0xFFFFFFFF、data_len<=maxPayload、checksum,再读 payload;失败返回 null
2. AdbConnection 在线循环:单线程读、分发 OPEN/WRTE/CLSE;写端用 synchronized 或单写线程
3. 经典 AUTH 状态机(见 PROTOCOL.md §2.3):TOKEN→SIGNATURE 验证→失败换 token 再发→RSAPUBLICKEY→onAuthorizationRequest 回调→允许则 TrustStore 落盘并发 CNXN
4. TLS 分支由 engine 完成(STLS 报文+SSLSocket),AdbConnection 只跑在已协商好的流上
5. CNXN 交换:AdbConnection 假定流已就绪,先读对方 CNXN,再发己方 CNXN(banner 由 engine 传入——增加构造参数 `localBanner: String`)
6. 公钥编解码:BigInteger 处理 n0inv=(-n^{-1} mod 2^32)、rr=2^4096 mod n;字节全部小端

### Task 2(卡片B,general-purpose):engine + platform

**Files:** `adbhost/src/main/java/com/adbhost/app/engine/*.kt`、`.../platform/*.kt`

**Interfaces(冻结):**
```kotlin
class AdbServiceController(context: Context) {   // 单例入口,UI 直接用
  val state: StateFlow<ServiceState>             // data class ServiceState(running, port, ip, error:String?)
  fun start(port: Int); fun stop()
  fun authorizationRequests: SharedFlow<AuthRequest>   // data class AuthRequest(fingerprint, name, kind, respond:(Boolean)->Unit)
  fun trustEntries: StateFlow<List<TrustEntry>>
  fun revokeTrust(entry: TrustEntry)
  val logs: StateFlow<List<LogLine>>             // data class LogLine(time, text)
  fun clearLogs()
}
class AdbServer(port: Int, controllerDeps...) {
  fun start(); fun stop();                       // accept 循环;每连接一线程;端口占用抛 PortInUseException
}
```
**关键实现要点:**
1. TLS 模式装配:accept→读对方 CNXN→发本地 CNXN→发 A_STLS→收到主机 A_STLS 后把 socket 升级为
   `SSLSocket`(服务端,needClientAuth=true,TLS1.3,自定义 X509TrustManager:取 peer cert 指纹→
   TrustStore 查→NEW 则经 controller 发授权请求**阻塞等待**(10s 超时=拒绝)→放行/拒绝;
   握手成功→取 TLS 流→交给 AdbConnection(再发 device CNXN——由 AdbConnection 的 CNXN 交换完成)
   - 证书:RsaIdentity 密钥 + BouncyCastle 自签(CN=adbhost,O=AdbKey-0),存 filesDir,首次生成
2. 经典模式装配:CNXN 交换后直接交 AdbConnection(tlsMode=false)
3. ShellService:服务名解析(shell:v2/v1、pty/raw、命令部分);ProcessBuilder;stdin/stdout/stderr 三线程泵;
   v2 帧 PROTOCOL.md §3;rootMode→`su -c sh -c <cmd>`(root 检测:`Runtime.exec("which su")` + 试跑 `su -c id`);
   连接断开 destroy() 进程
4. SyncService:PROTOCOL.md §3 sync;root 目录=App 外部私有目录(getExternalFilesDir);申请
   MANAGE_EXTERNAL_STORAGE 后同一目录模型不变(v1 不做全盘)
5. FeaturesService、未知服务 CLSE;AdbForegroundService(notification 含停止 action)、BootReceiver
6. IP 显示:遍历 NetworkInterface 找站点本地 IPv4;端口被占用(含系统 adbd 抢 5555)→ state.error 文案"端口被占用,请换端口(如 5556)"

**Steps:** 先 ShellService/SyncService 骨架+core 联调单测(engine 内可测的纯逻辑:服务名解析、sync 路径映射、v2 帧编解码)→ 装配 AdbServer → 前台服务 → `./gradlew assembleDebug test` 通过 → commit
